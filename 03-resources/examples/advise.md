# Here's how we'll practice

I won't give you the code.

I'll give you a real-world scenario.

You'll:

1. Understand the AWS service.
2. Find the Terraform resource.
3. Read the official documentation.
4. Identify:
   - Required arguments
   - Optional arguments
   - Attributes
5. Decide which values should be variables.
6. Write the code.
7. Run:

   ```Bash
   terraform fmt
   terraform validate
   terraform plan
   ```

8. Predict the plan.
I'll review it like a PR.
